## Saying Goodbye to GitHub Pages

I love GitHub Pages. Almost every single website I've built till now has been
hosted there. It's free, simple, and Jekyll-based – perfect for static sites
(which is what most people are hacking anyway). For the Office however, I
decided to not follow my usual convention and build my web server from scratch.

Amongst the reasons why this decision was made is I recently got a [HackClub Nest](https://hackclub.app)
container, with 2 cores and 2GB RAM which is more than enough to run
a web server + a few other things. With that, and I am getting older by the day
so I thought "why not learn how to build and maintain my own cloud-based web server?".

Another reason is flexibility. Building my own web server frees me from limitations
present in GitHub Pages (amongst it, static-sites only, limited to HTML/CSS/JS/Jekyll,
no backend execution or database). This enables me to build the Office to be scalable,
modular, and truly my way. Consequently, I am able to modify, add, and remove whatever
I want whenever.
