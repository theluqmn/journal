# Journal

![Hackatime Time](https://hackatime.hackclub.com/api/v1/badge/U082SDZLULQ/theluqmn/journal)
| [Website](https://theluqmn.hackclub.app/journal)

This is a repository that contains all the markdowns which makes up
my journal. The files are processed then served to the web by
[the Office](https://theluqmn.hackclub.app).

## Technicality

- The repository is cloned to The Office, then the markdown files inside
`/entries` are processed into HTML using Goldmark.
- The location of this project is the same as the Office in the server.
